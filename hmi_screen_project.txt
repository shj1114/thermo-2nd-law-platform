/**
 * 编译下载步骤：
 * 
 * 1. 点击 "工程" -> "编译" (或按 Ctrl+F5)
 *    编译成功后会生成 .bin 文件
 * 
 * 2. 下载到屏幕 (两种方式):
 * 
 * 方式A: SD卡下载 (推荐)
 *   a. 将 .bin 文件拷贝到SD卡根目录
 *   b. 确保文件名为: auto.bin (或原文件名)
 *   c. 将SD卡插入HMI屏幕
 *   d. 按下屏幕上的复位/升级按钮
 *   e. 等待升级完成 (屏幕会显示进度)
 *   f. 升级完成后自动重启
 * 
 * 方式B: USB串口下载
 *   a. 用USB转TTL模块连接电脑和HMI屏幕
 *   b. HMI屏幕TX接USB-RX, HMI屏幕RX接USB-TX
 *   c. HMI屏幕GND接USB-GND
 *   d. 在USART HMI软件中点击 "工程" -> "下载"
 *   e. 选择正确的COM口
 *   f. 点击下载，等待完成
 * 
 * 3. 连接MSPM0G3507测试
 *    a. 连接HMI屏幕到MSPM0G3507 (参考HMI串口屏配置指南.md)
 *    b. 下载MSPM0G3507程序
 *    c. 观察屏幕显示是否正常
 *    d. 测试交互功能
 */

/* ==================== 与MSPM0G3507通信协议 ==================== */

/**
 * MCU发送到HMI屏幕的指令 (以 C 代码形式):
 * 
 * // 初始化屏幕
 * printf("page 0");
 * HMI_SendEnd();  // 发送 0xFF 0xFF 0xFF
 * 
 * // 更新电流值
 * printf("prints n0,%d", current_value);
 * HMI_SendEnd();
 * 
 * // 添加曲线点
 * printf("add c0,%d", current_value);
 * HMI_SendEnd();
 * 
 * // 清除曲线
 * printf("cle c0");
 * HMI_SendEnd();
 * 
 * 
 * HMI屏幕返回给MCU的数据 (bkcmd=3):
 * 
 * 格式: 变量名.值\r\n
 * 
 * 示例:
 *   n0.125\r\n   -> 电流值为1.25A
 *   b0.1\r\n     -> 按钮b0(校准)被按下
 *   b1.1\r\n     -> 按钮b1(清零)被按下
 * 
 * 处理逻辑 (MSPM0G3507):
 * 
 * if (HMI_IsButtonPressed("b0")) {
 *     // 执行校准操作
 * }
 * if (HMI_IsButtonPressed("b1")) {
 *     // 执行清零操作
 * }
 */
