
 热力学第二定律量化综合实验平台
摘要  热力学第二定律是物理学热力学中重要的定律之一，其表述较为抽象及定性，本文以制冷原理知识为核心，设计并制作了一套热力学第二定律可视及定量的综合实验平台。该装置基于制冷技术，配合自主设计的可编程控制器PLC监测智能化、可视化平台，实现了热力学第二定律的定量可视化分析。本装置体积小，成本较低，能够实现较高的实验精度
关键字  热力学第二定律；制冷原理；定量化；可视化；智能化

1 研究背景
热力学第二定律作为热工核心理论，概念抽象难懂，根据美国PW Consulting 2025年热工教学设备调研报告显示，海外高校现有制冷实验设备造价高昂、仅能简单测温，缺少可实时生成热力曲线的低成本实物可视化平台，难以定量展示热量逆向传递规律，因此本装置结合真实制冷循环与自主PLC监测系统，低成本实现多参数同步采集，直观量化呈现热力学第二定律克劳修斯表述对应的热力过程，解决现有教学设备的缺陷。
2、物理原理
热力学第二定律是热力学的四个基本定律之一，它描述了能量转换和热传递的方向性。热力学第二定律有多种表述方式，最常见的两种表述是克劳修斯表述和开尔文-普朗克表述：
克劳修斯表述：不可能实现一个循环过程，其唯一结果就是从一个温度较低的热源向一个温度较高的热源传递热量
开尔文-普朗克表述：不可能从单一热源吸热使之完全转化为功而不产生其他效果
热力学第二定律的实验原理通常通过以下实验来验证：
卡诺热机实验：卡诺热机是一个理想化的热机模型，它只由两个等温过程和两个绝热过程组成。卡诺热机的效率只取决于两个热源的温度差，这表明了热机效率的上限，即不可能实现100%的热能转换为机械能
热电偶实验：通过测量不同温度下两种不同金属的接点产生的电压，可以验证热能转换为电能的效率和方向性
布朗运动实验：布朗运动是微小颗粒在液体中的随机运动，它表明了分子的无序运动，从而支持了熵增原理，即在一个孤立系统中，熵（无序度）总是倾向于增加
渗透压实验：渗透压实验展示了不同浓度溶液之间的物质传递，表明了物质总是从高浓度区域向低浓度区域自发扩散，直到达到平衡状态
制冷循环实验：制冷循环是热力学第二定律的一个应用，它展示了如何通过消耗外部能量（如电能）来实现热量从低温向高温的非自然传递
这些实验不仅验证了热力学第二定律的正确性，而且帮助我们理解了能量转换和热传递的基本原理。
本装置在制冷循环实验的基础上，对热力学第二定律实验进行综合型设计，增强学生对热学的综合认识；分立式搭建量化综合实验平台，提高学生的动手能力以及加深对热学工作原理的直观认识。

4．数据可视化系统设计
在完成硬件装置与 PLC 数据采集的基础上，本项目自主开发了一套制冷循环数据可视化系统，将 PLC 现场采集的温度、压力、电压、电流等数据实时转换为四类专业热力分析图（P-h 压焓图、T-s 温熵图、熵流曲线、COP 曲线），并支持交互式缩放、平移、悬停查值与数据的本地 Excel 导出。系统全部功能在浏览器端离线完成，绘图、坐标运算、工质物性计算及 Excel 文件生成均不依赖任何第三方图形库或图表框架，而是基于 HTML5 Canvas 从零实现自定义渲染管线，保证在无网络的实验现场稳定运行
4.1  数据流与实时刷新机制
数据从现场到图形共经过四个环节：采集、计算、渲染与联动。首先，本机网关程序以 MC 通讯协议读取 PLC 的 D 寄存器，将温度、压力、电压、电流等物理量整理为统一的 JSON 数据结构，经本机 HTTP 服务推送至浏览器界面；当无 PLC 连接时，系统自动切换为模拟数据源以便离线演示与调试。其次，界面在每次采集后由实测高、低压反推制冷循环的四个状态点，并计算 COP、熵流等衍生量。最后，将循环状态与历史序列绘制到 Canvas 画布。采集周期在以太网网关模式下为 2 秒、模拟模式下为 1 秒；所有图表与导出数据均由同一采集循环驱动，随实测数据同步变化。

图10  数据可视化系统数据流示意图
4.2  制冷循环热力建模
可视化的前提是将少量实测量还原为完整的循环状态。系统内置 R22 制冷剂的饱和物性近似表（温度区间 −40～60 ℃），列出各温度下的饱和压力、饱和液与饱和气比焓（hf、hg）及比熵（sf、sg），运行时以线性插值求取任意温度或压力下的物性值，并提供由压力反查饱和温度的函数，作为所有曲线的数值基础。
在此基础上，由实测高压 P1、低压 P2 分别反推冷凝饱和温度 Tc 与蒸发饱和温度 Te，构建理想蒸气压缩制冷循环的四个状态点：状态 1 为蒸发器出口的低压饱和气；状态 2 为压缩机出口，经等熵压缩至高压后进入过热区，其过热温升由过热蒸气定压比热（约 0.70 kJ/(kg·K)）近似估算；状态 3 为冷凝器出口的高压饱和液；状态 4 为经等焓节流后的低压两相状态。
由四状态点可进一步计算循环性能指标：单位质量制冷量 q₀ = h₁ − h₄，单位质量压缩功 w = h₂ − h₁，实际制冷系数 COP = q₀ / w，卡诺理论上限 COP_carnot = Te /(Tc − Te)。实际 COP 恒小于同温区的卡诺上限，符合热力学第二定律，可作为循环完善程度的参照。熵流则按下式定义（分母取开尔文换热温度）：
SF1 = 1.005 ×(冷凝出口四点均值 − 环境温度)/(273 + 冷凝器工质温度)
SF2 = 1.005 ×(环境温度 − 蒸发出口四点均值)/(273 + 蒸发器工质温度)
熵流 = SF1 + SF2
公式中系数 1.005 为空气定压比热 kJ/(kg·K)。SF1 表征冷凝放热侧熵流、SF2 表征蒸发吸热侧熵流，二者之和即系统对外释放的总熵流。
4.3  自定义 Canvas 渲染管线
渲染是数据可视化的技术核心。系统未采用任何现成图表库，而是实现了一个通用绘图器，四张图共用同一套坐标映射与交互逻辑。从物理数据到屏幕像素经过三级映射，逐级解耦：第一级由数据域映射到 [0,1] 归一化区间，同时支持线性轴与对数轴两种方式，其中压力轴（P-h 图纵轴）采用对数映射、其余采用线性映射；第二级引入视图状态（X/Y 缩放倍率与偏移量），将归一化坐标映射到当前可视窗口，实现任意区段的放大；第三级结合绘图区尺寸与内边距，落到 Canvas 屏幕坐标。三级串联后，任意物理值都能定位到当前视图下的像素位置。
为保证可读性，坐标框与轴刻度始终绘制在绘图区边缘：先绘制网格与刻度，再绘制坐标边框，最后将曲线裁剪到绘图区内，防止曲线溢出坐标框。刻度值随可视范围动态生成——线性轴按跨度反推 1、2、5×10ⁿ 的整齐步长，对数轴在每个数量级上取 1、2、5 三档，因此画面放大后刻度自动加密、缩小后自动稀疏，且刻度与曲线严格对齐。绘制循环轨迹前，系统会把可能超出饱和穹顶的压缩过热点纳入坐标范围，避免节点越出画框导致循环画不完整。此外，画布按设备像素比放大物理像素，保证高分屏下曲线与文字清晰。


图11  P-h 压焓图与 T-s 温熵图实时循环
对于熵流与 COP 这类随时间累计的时序曲线，系统维护固定长度的历史缓冲，且即使弹窗未打开也持续累计，因此用户打开对应图时可立即看到一段完整曲线而非从空白开始；COP 图同时叠加卡诺上限（虚线），直观显示实际效率与理论极限的差距。

4.4  交互设计
四张图共享一套鼠标交互，全部围绕视图状态的增量更新，修改后即时重绘。滚轮缩放以光标位置为锚点，将横纵坐标同步按固定倍率缩放：先把光标屏幕坐标反算成全域归一化坐标，缩放后调整偏移量使光标下的数据点保持不动，从而实现"跟手"缩放，缩放倍率限制在 1～20 倍。拖动平移通过记录起始偏移，将屏幕像素位移除以缩放后的绘图区尺寸换算成归一化偏移量，实现等速拖动，并约束偏移不越过数据边界。悬停查值在鼠标停留约 0.5 秒后触发，对当前图记录的可悬停点集做最近邻查找，命中阈值内即在指针旁弹出该点的数据属性（如状态点的焓、压力、温度）。上述交互所需的屏幕坐标到数据坐标的逆映射，与绘制过程共用同一套坐标基准，保证交互与显示严格一致。
4.5  数据的 Excel 导出
系统提供数据导出功能，可将采集过程中的温度数据保存为本地 Excel 文件，且在无第三方库的前提下直接生成符合 OOXML 标准的 .xlsx 文件。自软件运行起，每次采集向导出缓冲追加一行，并节流写入浏览器本地存储（约每 3 秒落盘一次），页面刷新或软件重启均不丢失数据，记录上限 2 万行、超出后滚动丢弃最早记录。
xlsx 文件本质是一个包含多个 XML 部件的 ZIP 压缩包，其生成分两层实现：一是按标准组装内容类型声明、关系文件、工作簿、样式表与工作表等 XML 部件，工作表严格按规定顺序输出尺寸声明、列宽、数据与合并单元格，这是文件不被 Excel 判为损坏而丢失合并的关键；二是手写 ZIP 打包，采用存储法逐个写入本地文件头、数据、中央目录与结尾记录，并自实现 CRC32 校验各部件，最终封装触发下载。导出表格采用两行合并表头：首列至"高低温温差"各列纵向合并跨两行，"冷凝器出口温度""蒸发器出口温度"各横向合并覆盖其下测点 1～4，数据自第三行起排列，合并区内的空格也赋予表头样式以保证边框与底色完整。

4.6  技术特点小结
本数据可视化系统具有以下特点：一是零依赖离线运行，物性插值、Canvas 绘图、缩放平移查值交互及 xlsx 生成全部自主实现，不联网、不引入外部库；二是统一渲染管线，四图共用三级坐标映射与通用绘图器，兼容线性与对数坐标，坐标系常驻且刻度自适应；三是交互跟手，以光标为锚点的同步缩放与等速拖动配合最近邻悬停查值；四是实时联动，图表与导出数据由同一采集循环驱动、随实测同步变化，历史缓冲保证时序曲线随开随现；五是工程严谨，绘图范围自适应过热点不越界、COP 受卡诺上限约束、导出文件严格符合 OOXML 规范。该系统显著提升了实验数据的直观性与可分析性，为热力学第二定律的定量分析提供了有力工具。

5、本实验目的与原理
5.1实验目的
了解卡诺循环的运行特性，定性验证热力学第二定律
了解熵法和㶲法，定量计算验证热力学第二定律
掌握热力学第二定律的克劳修斯表述

5.2实验原理
热力学第二定律的实质为：论述热力过程的方向性及能质退化或贬值的客观规律，热力过程具有方向性这一客观规律，由于不同类型或不同状态下的能量具有质的差别，而过程的方向性正缘于较高能质到较低能质的转化。例如，热量有高温传至低温，机械能转化为热能，按热力学第一定律能量的数量保持不变，但是以做功能力为标志的能质却降低了，即为能质的退化或贬值。
热力学第二定律的克劳修斯标书为不可能把热量从低温物体传到高温物体而不引起其他变化。此种说法指出了在自然条件下热量只能从高温物体向低温物体转移，而不能从低温物体向高温物体转移，也就是说在自然条件下，这个转变过程是不可逆的，要使得热传递过程倒转过来，只有靠消耗功实现。
空调制冷系统是一套完整的逆卡诺循环系统，实验时压缩机工作，使卡诺管内的工质（理想气体）循环流动，于是在高温热源处内部压力增加，工质凝结放热，温度升高，高温热源向外界放热，内部工质经毛细管自发的流向低温热源。在低温热源处内部压力降低，工质蒸发吸热，温度降低，低温热源从外界吸热，最后工质又流向低温热源。在低温热源处内部压力降低，工质蒸发吸热，温度降低，低温热源从外界吸热，最后工质又流向压缩机，经压缩机加压开始新的循环，整个工质过程就是一个逆卡诺循环过程，循环过程如图14所示。

图14循环系统示意图
以上是对热力学第二定律的定性论述，定量的计算要通过状态参数熵的计算来实现，根据热力学第二定律的论述，一切实际过程都是不可逆过程，都伴随着熵的产生和做功能力的损失，即热力系统过程中必然存在熵增现象。又由于空调系统主要是压缩机做功使内部工质的物态发生变化来完成的，压缩机将电能转化为机械能，最终转化为内能，按热力学第一定律能量的数量不变，但是以做功能力来标志的能质却降低了。

6、实验步骤
实验要求
（1）预习实验指导书，了解热力学第二定律克劳修斯表述，编制数据记录表格；
（2）掌握热力学第二定律克劳修斯表述的含义；
（3）掌握定量计算验证热力学第二定律正确性的方法。
实验注意事项：
不要用手直接触摸空调系统，防止烫伤或冻伤。
制冷系统直观的显示卡诺循环过程，直接感受到冷凝器工质冷凝向空气中放热及蒸发器工质蒸发从空气中吸热，验证热力学第二定律的正确性。
控制系统显示空调制冷系统工质的压力和温度以及环境温度数据变化，通过状态参数熵或㶲计算说明热力学第二定律的正确性。
（1）实验之前，先了解实验要求，漏电保护开关和旋钮开关处于关闭状态，盛水槽中无积水。
（2）打开漏电保护器开关，智能温度调节仪表读数显示清晰、无断码，且2个四路温控仪表读数之间温差不大于2℃，记录环境温度（2个四路温控仪表读数的平均值），高低压压力表读数一致。
（3）打开空调系统开关。压缩机开始工作，冷凝器内部压力增加，产生高温高压的气体，由于节压阀的存在，高温高压气体在通过节压阀之前开始凝结，变成高压液体，内部温度上升，高温热源开始自发的向外界放出热量，将手放在冷凝器前可感受到吹出热风。又由于节压阀的存在，使蒸发器内部压力很低，由节压阀过来的工质在其附近变成低压液体，在蒸发器内开始蒸发，内部温度下降，低温热源开始自发的从外界吸收热量，将手放在蒸发器前可感受到吹出冷风，最后卡诺管中的工质又流回压缩机中，通过压缩机做功开始新的一个循环，可以看出低温低压工质转变为高温高压工质，必须有一个外加的压缩机做功来实现，不能够自发的完成。通过空调系统运行特性的学习定性验证热力学第二定律的正确性。
（4）空调系统运行一段时间（五分钟左右），实验参数稳定下来后，记录实验数据，并对实验数据进行计算，定量验证热力学第二定律的正确性。
（5）实验完毕，首先关闭空调系统开关，再关闭漏电保护开关，将盛水槽中的污水清理干净，并按要求整理实验台。

创新点一：可视化，本装置为可以实现电功率输出的“热机”，并且具有可视化的展示功能，设备具有安全性，制冷装置表面（可触摸到的）温度不高于50℃。 热力学第二定律定量综合实验台主要有制冷空调系统、测量装置及智能化控制系统三部分组成。通过实物、数据定量性验证热力学第二定律克劳修斯表述。采用熵增原理定量验证热力学第二定律克劳修斯表述的正确性。
创新点二：定量化，制冷空调系统直观的显示卡诺循环过程，直接感受到冷凝器工质冷凝向空气中放热及蒸发器工质蒸发从空气中吸热，并通过状态参数熵或㶲计算说明热力学第二定律的正确性。
创新点三：控制智能化；仪表通过Modbus RTU通讯协议于PLC通讯，显示空调制冷系统工质的压力和温度以及环境温度数据，通过串口通讯线与PLC进行数据交换，使得所有仪表数据直接显示在触摸屏，实现智能可视化。
综上，本综合试验台设计紧凑，更好利用了平台空间，并且拥有较为全面的功能， 测试手段先进，精度较高，在系统设计时，充分考虑测试对象及要求等各方面因素，采用合理、先进的测试技术和设备。
10、实验总结与展望 
实验总结
本装置以真实制冷循环搭建逆向传热热力实验平台，核心创新为基于PLC控制器开发全流程定量可视化监测系统，可同步采集多路温度、压力、电功率数据并实时生成热力曲线图，设备运行安全可靠，直观具象化验证热力学第二定律，量化分析热量传递的不可逆方向性。经多组实验数据演算与现象观测，所得规律与克劳修斯理论完全契合，同时分析了系统测量误差及当前硬件设备存在的性能局限
