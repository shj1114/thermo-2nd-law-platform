/* ==================== 操作说明 ==================== */

/**
 * 使用步骤：
 * 
 * 1. 下载并安装 USART HMI 软件
 *    - 下载地址：http://www.tjc1688.com/download/usart_hmi.html
 * 
 * 2. 创建新工程
 *    - 打开软件 -> 文件 -> 新建工程
 *    - 选择屏幕型号：HMI01-0430 (480×272 IPS)
 *    - 或 HMI01-0430 (800×480 IPS)
 *    - 设置工程参数为上方配置
 * 
 * 3. 设计页面
 *    - 在"页面"面板添加页面
 *    - 选择页面0，按照上方说明添加控件
 *    - 每个控件设置属性和事件
 * 
 * 4. 编写程序
 *    - 每个按钮的按下事件中添加发送代码
 *    - 格式：printh 按键码 0d 0a
 *    - b0校准: printh 30 0d 0a
 *    - b1清零: printh 31 0d 0a
 * 
 * 5. 编译下载
 *    - 工程 -> 编译 (或Ctrl+F5)
 *    - 将编译生成的 .bin 文件拷贝到SD卡
 *    - 插入SD卡到HMI屏幕
 *    - 按屏幕复位键更新固件
 *    - 或使用USB串口在线升级
 * 
 * 6. 与MSPM0G3507连接测试
 *    - 接线参考 HMI串口屏配置指南.md
 *    - 下载 MSPM0 程序到开发板
 *    - 观察屏幕显示是否正常
 *    - 测试按钮交互功能
 * 
 * 通信协议说明：
 * 
 * MCU发送到HMI的指令格式：
 *   指令内容 + 0xFF 0xFF 0xFF (三个结束字节)
 * 
 * HMI返回给MCU的数据格式 (bkcmd=3):
 *   变量名.值\r\n
 *   例如: n0.123\r\n 表示变量n0的值为123
 * 
 * 按钮事件处理：
 *   - 按钮按下时，HMI发送按钮ID+".1\r\n"到MCU
 *   - MCU收到后解析并执行相应操作
 *   - 例如: b0.1\r\n 表示按钮b0被按下
 */

/* ==================== 常用指令速查 ==================== */

/**
 * MCU控制HMI屏幕指令列表：
 * 
 * page N        - 跳转到页面N
 * prints N,V    - 设置整型变量N的值为V
 * prstr N,S     - 设置字符串变量N为S
 * vis N,F       - 显示/隐藏控件N (F=1显示, F=0隐藏)
 * tsw N,F       - 启用/禁用控件N的触摸功能
 * add C,V       - 向曲线控件C添加数据点V
 * cle C         - 清除曲线控件C的数据
 * ref N         - 刷新/重绘控件N
 * rest          - 复位屏幕
 * click B       - 触发按钮B的按下事件
 * 
 * 所有指令必须以 0xFF 0xFF 0xFF 结尾
 * 
 * 示例 (C代码):
 *   // 跳转到页面0
 *   printf("page 0");
 *   HMI_SendEnd();  // 发送三个0xFF
 * 
 *   // 设置数值
 *   printf("prints n0,123");
 *   HMI_SendEnd();
 * 
 *   // 添加曲线点
 *   printf("add c0,50");
 *   HMI_SendEnd();
 */
